# Hackathon Pitch

## One-line pitch

TrueSource is a knowledge control plane that stops enterprise AI from learning stale documentation by continuously reconciling docs against live operational evidence.

## 30-second elevator pitch

Enterprise AI fails when documentation drifts from reality. TrueSource monitors operational systems and documentation together, detects contradictions, explains what changed, and routes fixes through human approval before refreshing trusted knowledge. Instead of faster wrong answers, teams get verified answers with provenance, confidence, and audit history.

## 2-minute judge pitch

Every company has two versions of truth: what teams do in systems, and what docs say on paper. AI assistants usually trust the paper version.

TrueSource is the missing control plane between enterprise reality and enterprise AI. We scan source systems like cloud runtime, code pipelines, and ticketing tools, then compare them with knowledge systems like Confluence and SharePoint. If they disagree, TrueSource raises a knowledge incident with evidence, confidence scoring, and proposed document updates.

A reviewer approves the fix, and TrueSource updates the verified knowledge layer that downstream assistants use for retrieval. That means AI answers are not only fluent, but current, explainable, and auditable.

The result is simple: fewer hallucinations, faster incident response, and governance-ready AI adoption.

## Live demo talk track (3 minutes)

1. Start with the question: "How is Payments deployed?"
2. Show stale answer from outdated docs (EC2).
3. Trigger migration simulation to EKS.
4. Run scan and show cross-system evidence collection.
5. Open the incident and highlight contradiction confidence and proposed diffs.
6. Approve remediation and show documents updated.
7. Ask again and show verified EKS answer with trust metadata.
8. Close with: "TrueSource ensures AI learns from reality, not residue."
